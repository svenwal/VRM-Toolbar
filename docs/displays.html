Displays

A display is one value, shown in the menu bar, the Dock icon or a floating window.

The Displays page

The list on the left is grouped by where each display appears: Menu bar, Dock icon and one group per floating window. Groups collapse. Hover a row to reveal move up/down arrows and a delete button, or drag rows to reorder them within their group. The editor on the right changes the selected display.

Targets

TargetWhat you get
Menu barOne status item per display, with an optional SF Symbol in front and the value as text. Dimmed when the data is stale.
Dock iconThe Dock tile renders up to three values over an electric-blue badge. The Dock icon is always visible by default; with Always show Dock icon turned off, it appears only while a display uses it.
Floating windowA translucent, always-on-top panel with any number of values. See Floating windows.

Options

OptionEffect
LabelOverrides the name shown for the value.
UnitReplaces the unit VRM reports, for example % for a tank level.
SF SymbolMenu bar only. Any SF Symbols name, such as bolt.fill or battery.100.
Hero valueFloating windows only. Marks the one big value in the Hero layout. Only one per window.
Only show while activeHides the display while the value is at or below a threshold. Perfect for shore power or AC input that should vanish when you are unplugged.
InstallationWhich of your installations the value comes from. Shown when you have more than one.

Finding a value

The list shows every value your installation reports, with its current reading. Use the search field to filter. A ⚡ marks values delivered by the live stream.

Hover for history

Hover over a menu bar item or a value in a floating window to open a line chart of the last 24 hours with min, max and average. See Live data & history.
