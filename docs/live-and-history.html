Live data & history

Values stream in the moment they change, and every value has a chart behind it.

Live stream

With an access token, VRM Toolbar connects to the VRM MQTT broker over secure WebSockets for each installation. Streamed values (⚡ in the value list) update instantly, with no polling delay. If the connection drops, the app reconnects on its own.

Polling

The VRM API is polled on a schedule (default every 60 seconds, see General settings). When streaming is active, polling mostly refreshes the list of available values. If you sign in with a password, the app polls only.

History chart

Hovering a display opens a chart with the last 24 hours. For values VRM stores history for, the data comes from VRM at 15-minute resolution. For anything else the chart is built from samples collected since the app launched. Min, max and average are shown alongside the current value, and the chart uses the window’s typeface and accent colour.

Stale data

If no fresh data arrives for a while, menu bar items are dimmed so you do not mistake an old number for a current one.
