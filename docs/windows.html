Floating windows

Create as many always-on-top panels as you like, each with its own look.

Managing windows

Open Windows and press New window. Each window has a name, a visibility toggle and a style. A live preview sits on a colourful backdrop so transparency is easy to judge. Assign values to a window from Displays › Show in › Floating window. Drag a window on the desktop to place it, the position is remembered.

Context menu

Right-click a floating window for Settings…, Refresh, Hide This Window and Quit.
