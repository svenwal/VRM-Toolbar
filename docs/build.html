Build from source

VRM Toolbar is a Swift package with no third-party dependencies.

Requirements

  • macOS 14 or newer
  • Xcode 16+ or the matching command line tools (Swift 6 toolchain)

Build & run

./scripts/bundle.sh          # release build → build/VRMToolbar.app
open build/VRMToolbar.app

The script builds a release binary, wraps it in an app bundle (bundle id world.walther.vrm-toolbar) and signs it.

Code signing

The script picks the first Apple Development identity in your Keychain. Override with:

SIGN_IDENTITY="Apple Development: Your Name (TEAMID)" ./scripts/bundle.sh

Without an identity it falls back to an ad-hoc signature. That works, but macOS will ask for Keychain access again after each rebuild.

Tests

swift test

Covers configuration decoding, the VRM client and stats parsing, and the MQTT packet codec.
