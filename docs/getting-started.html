Getting started

From download to your first live battery readout in about five minutes.

What you need

  • A Mac running macOS 14 Sonoma or newer. Liquid Glass styling is used on macOS 26 and falls back to system materials on older versions.
  • A Victron installation that reports to the VRM portal (a GX device such as a Cerbo GX, or a VRM-connected Venus OS).
  • A VRM account. An access token is recommended.

1. Install

There are no prebuilt releases yet, so build the app yourself. It takes one command and needs the Xcode command line tools:

git clone https://github.com/svenwal/VRM-Toolbar.git
cd VRM-Toolbar
./scripts/bundle.sh
open build/VRMToolbar.app

See Build from source for details, including code signing.

2. Sign in

On first launch the settings window opens on the Account page. Paste a VRM access token (how to create one) and press Sign in. The app reads your installations and starts listening for values.

3. Add a display

  1. Open Displays and press Add display.
  2. Choose Show in: Menu bar, Dock icon, Floating window or Widget.
  3. Pick a value from the list, for example Battery state of charge. Values marked with ⚡ are streamed live.
  4. Optionally set a label, unit or SF Symbol.

It appears immediately. Add as many as you like, and drag them to reorder.

TipAdd a battery state of charge value to make the whole app react to it. The Overview ring and the animated background shift from green to amber to red as the charge drops.

Where it lives

VRM Toolbar is a menu bar app. It keeps a Dock icon by default (switch this off under General), and the Dock tile can show values too. Click the menu bar value for the current readings, Refresh, Settings… and Quit.
