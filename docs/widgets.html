Widgets

Collect values into sets, and show each set in its own Notification Center or desktop widget.

Widget sets

Just like floating windows, you can create as many widget sets as you like. Open Widgets in the app and press New widget set. Give it a name such as “Boat” or “Energy”. Each set is a collection of values.

Putting values into a set

  1. Open Displays and add a display (or select one).
  2. Choose Show in › Widget and pick the Widget set.
  3. Pick the value. Its label and unit apply, and Only show while active hides it from the widget too.

The set appears as its own group in the Displays list. Reorder the values there, widgets show them in that order. A display belongs to exactly one place, so add the same value twice if you want it in the menu bar and in a widget.

Adding a widget

  1. Start VRM Toolbar at least once, so macOS discovers its widgets.
  2. Click the clock in the menu bar, scroll down and choose Edit Widgets. You can also right-click the desktop.
  3. Search for VRM Toolbar, pick a widget and size, and add it.
  4. Right-click the widget, choose Edit Widget and select the widget set it should show.

Add the same widget several times with different sets, for example a small Battery for the boat and another for the cabin.

Available widgets

WidgetSizesShows
BatterySmall, MediumA state-of-charge ring in the app’s green, amber and red. The medium size adds the first three values of the chosen set.
ValuesSmall, Medium, LargeThe first 3, 4 or 8 values of the chosen set.

Both use the dark, glowing look of the app, and the glow follows your charge level.

No set chosen?A new widget shows the first set until you pick one. If a set has no values yet, the widget tells you where to add some.

How fresh is the data?

The app hands its current values to the widgets and asks macOS to redraw them, at most about every 30 seconds. macOS decides when a widget is really redrawn, so it can lag behind the live menu bar. The corner of the widget shows the set name and when the app last received data, in orange when the data is stale.

Widgets only update while VRM Toolbar is running, so enable Launch at login. Without the app, they keep showing the last values.

Under the hood

Widget extensions are sandboxed and have no network access, so the app writes a small snapshot file with all sets into a shared app-group container, and each widget picks its set from it. Your VRM credentials never leave the app.

Self-built appWidgets need the app to be code-signed. Build with an Apple Development identity (see Build from source), and keep the app in a fixed place such as Applications.
