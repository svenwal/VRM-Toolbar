Features

Everything a glance should tell you.

Designed like the rest of macOS: translucent, calm and quick to read.

⚡

Live streaming

Values arrive over VRM’s MQTT broker the moment they change. No waiting for the next poll.

📍

Menu bar, Dock & windows

Show any value as a menu bar item with an SF Symbol, on the Dock tile, or in floating panels.

🎨

Four materials, three layouts

Glass, Frosted, Solid or Neon. List, Tiles or Hero. Your accent, your typeface, your corners.

📈

Hover for history

Hover any value for a 24-hour chart with min, max and average.

🫥

Show only when relevant

Hide shore power when you are unplugged. Displays can disappear below a threshold you choose.

🔐

Private by design

Talks only to Victron. Credentials stay in your Keychain. No telemetry, no dependencies.

Floating windows

Make it look like yours.

Create as many windows as you want. Same data, four moods.

Setup

Up and running in minutes.


  1. Build the appClone the repo and run ./scripts/bundle.sh.
  2. Paste your VRM access tokenCreate it under VRM › Preferences › Integrations.
  3. Pick the values you care aboutChoose a place for each one, and you’re done.
